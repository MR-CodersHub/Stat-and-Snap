# Stat & Snap — Local Sports Team Photography & Yearbook Service

Stat & Snap is a premium, highly polished web application for high school athletic departments, sports academies, and youth leagues. It provides team photography booking, individual athlete media days, and turnkey yearbook PSPA roster synchronization.

Built with **100% HTML5, CSS3, and Vanilla JavaScript (ES6)**. Zero external frameworks.

## 🎨 Visual Identity & Design System
- **Midnight Navy**: `#111C2D`

## 🌐 Features
- **14 Complete Web Pages & Views**
- 🌗 **Light / Dark Mode**: Toggle with LocalStorage persistence.
- 🔄 **RTL / LTR Direction**: Full right-to-left layout recalculation.
- 📊 **School Client Dashboard**: 16 sidebar modules, 11 summary widgets, live roster search, status filters.
- 🖼️ **Lightbox Gallery**: Full resolution modal preview.
- 🍞 **Toast Notification System**: Real-time action feedback.
- 📋 **Form Validation**: Client-side interactive forms.
